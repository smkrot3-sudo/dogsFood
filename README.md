# אניפט — סורק מחירים 🐾

אפליקציית ווב לטלפון (מותאמת לאנדרואיד/Chrome) לעובדי חנות אניפט:
סורקים ברקוד של מוצר מהמצלמה — או מזינים ידנית מספר/שם — ומקבלים מיד את
**שם המוצר והמחיר העדכני** לפי האתר של אניפט. בנוסף יש עמוד שמראה **שינויי מחירים**
מהבדיקה היומית.

🔗 **חי בענן:** https://smkrot3-sudo.github.io/dogsFood/
📁 **מאגר GitHub:** https://github.com/smkrot3-sudo/dogsFood

---

## איך זה עובד (בקצרה)

- פעם ביום מורידים את כל קטלוג המוצרים של אניפט (מקובץ ציבורי `products.json` באתר),
  בונים אינדקס `ברקוד → שם + מחיר`, ומשווים לבדיקה הקודמת כדי לזהות שינויי מחיר.
- הטלפון פותח עמוד ווב, סורק ברקוד, ומחפש התאמה באינדקס — מהיר מאוד, ועובד גם בלי
  אינטרנט אחרי טעינה ראשונה (נשמר מטמון מקומי).
- **הברקוד מגיע מהשדה SKU של המוצר באתר.** רוב המוצרים (~1,700 מתוך ~2,000) הם ברקודי
  קמעונאות תקניים (EAN-13/UPC/EAN-8) שנסרקים כרגיל. חלק קטן משתמש בקוד פנימי קצר שלא
  ניתן לסריקה — אותם מוצאים לפי **חיפוש בשם** או הזנה ידנית.

## שימוש רגיל (בענן — אין צורך להריץ כלום)

האתר חי ב-**https://smkrot3-sudo.github.io/dogsFood/** ומתעדכן לבד כל בוקר. פותחים
את הקישור בטלפון, מוסיפים למסך הבית, וזהו. השלבים למטה נחוצים רק לפיתוח/בדיקות מקומיות.

## הרצה מקומית (לפיתוח בלבד)

1. פותחים את התיקייה `C:\dev\code\dogsFood`.
2. לחיצה כפולה על **`start-server.bat`** (או בטרמינל: `npm start`).
3. פותחים בדפדפן במחשב: **http://localhost:3000**

## שימוש מהטלפון (אנדרואיד, אותה רשת Wi-Fi)

1. משאירים את השרת רץ במחשב (שלב 2 למעלה).
2. בטלפון פותחים ב-Chrome את הכתובת המאובטחת שמופיעה בחלון השרת, למשל:
   **`https://192.168.68.123:3443`** (המספר משתנה לפי הרשת שלך).
3. בפעם הראשונה יופיע אזהרת אבטחה ("החיבור אינו פרטי") — זה בגלל תעודה מקומית שלך.
   לוחצים **מתקדם → המשך בכל זאת**.
4. מאשרים גישה למצלמה, לוחצים **"התחל סריקה"**, ומכוונים לברקוד.
   > 💡 אפשר "להוסיף למסך הבית" כדי שייראה כמו אפליקציה.

## הבדיקה היומית (שינויי מחירים)

**רצה לבד בענן כל יום ב-08:00** (שעון ישראל, קיץ) דרך GitHub Actions —
אין צורך שהמחשב יהיה דלוק. כל הרצה מורידה קטלוג עדכני, משווה לבדיקה הקודמת,
ומעדכנת את עמוד **"שינויי מחירים"** (גם שינויי הבדיקה האחרונה, וגם ארכיון היסטורי מלא):
https://smkrot3-sudo.github.io/dogsFood/changes.html

- **להריץ ידנית מהענן:** בעמוד המאגר ב-GitHub → לשונית **Actions** →
  "Daily price check" → **Run workflow**.
- **לשנות שעה:** עורכים את `cron` בקובץ `.github/workflows/daily.yml`
  (GitHub עובד ב-UTC, בלי שעון קיץ/חורף).
- **להריץ מקומית (אופציונלי, לבדיקות):** לחיצה כפולה על **`daily-check.bat`**
  (או `npm run check`), או לתזמן ב-Windows Task Scheduler:
  ```bat
  schtasks /Create /SC DAILY /ST 06:00 /TN "Anipet price check" /TR "\"C:\dev\code\dogsFood\daily-check.bat\""
  ```
  ביטול: `schtasks /Delete /TN "Anipet price check" /F`

## מבנה הפרויקט

```
dogsFood/
├─ server.js              שרת מקומי לפיתוח (HTTP ל-PC, HTTPS לטלפון)
├─ start-server.bat       הפעלת השרת המקומי בלחיצה כפולה
├─ daily-check.bat        הרצת הבדיקה היומית ידנית/מקומית
├─ scripts/
│  └─ fetch-catalog.js    הורדת הקטלוג + זיהוי שינויי מחיר
├─ .github/workflows/
│  └─ daily.yml           הבדיקה היומית האוטומטית בענן (GitHub Actions)
├─ docs/                  האפליקציה עצמה — זו התיקייה ש-GitHub Pages מגיש
│  ├─ index.html / changes.html   עמוד הסורק ועמוד השינויים
│  └─ data/               נתונים שנוצרים (קטלוג, שינויים, היסטוריה)
└─ certs/                 תעודת HTTPS מקומית (לפיתוח בלבד, לא עולה ל-git)
```

## הערה חשובה לבדיקה בחנות

מומלץ בהתחלה לסרוק כמה מוצרים אמיתיים ולוודא שהברקוד הפיזי שמודפס על האריזה תואם
למחיר הנכון באתר. למוצרי יצרן זה כמעט תמיד יתאים; אם ייתקלו במוצר שלא נמצא — כנראה
שהוא מהקבוצה הקטנה עם קוד פנימי, ואפשר לחפש אותו לפי שם.
